## 🚀 Lancer le site en local

Aucune installation n'est nécessaire : il suffit de cloner le dépôt et d'ouvrir `index.html` dans un navigateur.

```bash
git clone https://github.com/bastienblmy/bastienblmy.github.io.git
cd bastienblmy.github.io
```

Pour un rendu plus fidèle (chemins relatifs, etc.), vous pouvez aussi lancer un petit serveur local :

```bash
python -m http.server 8000
```

puis ouvrir [http://localhost:8000](http://localhost:8000).
